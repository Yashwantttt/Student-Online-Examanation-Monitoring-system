# Student Online Examination / Assessment Management System (Frontend Prototype)

A responsive, frontend-only web prototype for the **Student Online Examination / Assessment Management System**, built for our Software Engineering Lab project based on the Version 1.0 SRS.

> **Note:** This is a static UI prototype using mock data and client-side JavaScript for view switching and basic interactions. No backend or database is connected yet.

## Features Implemented (UI)

* **Authentication & Role Switching:** Login interface with role-based routing for Student, Faculty, and Administrator views.
* **Student Dashboard:** View available examinations, read pre-exam instructions, attempt objective-type questions with question navigation, submit exams, and view results.
* **Faculty Dashboard:** Create, edit, and publish examinations, manage the objective Question Bank, and monitor student attempts and performance.
* **Administrator Dashboard:** View and manage registered users, assign roles, and oversee examination records.

## Tech Stack

* **HTML5** – Structure and semantic layout
* **Tailwind CSS** – Styling and responsive design
* **Vanilla JavaScript** – Client-side navigation and mock interactions

## How to Run

1. Download or clone the repository.
2. Open `index.html` directly in any modern desktop/laptop web browser (Chrome, Edge, Firefox, Safari).
3. Use the login screen to switch between **Student**, **Faculty**, and **Admin** dashboards.
